# 六项优化实施与验收

授权：用户明确要求完成上轮列出的六项。保留现有主题、布局和终端快捷键，完成后构建可执行 JAR，不提交、不推送、不连接保存的服务器。

1. 在线编辑：读取源版本/内容，保存前冲突检测，比较/重新加载/另存及明确覆盖选择；临时文件发布；失败保留本地内容。
2. 批量文件：Ctrl/Shift 多选、批量下载、批量删除；确认列出真实选择，后台操作固定绝对路径。
3. 文件夹传输：递归上传下载与拖入，目录结构与空目录保留；分组总进度/取消/失败项重试；不跟随符号链接，不允许远端名称逃逸本地目标目录。
4. 终端文件衔接：可开关的可信目录事件跟随、目录书签、显式触发的远程路径补全。Shell 集成只在当前会话经用户明确触发，不修改启动文件；不把 exec pwd 当成交互 Shell 当前目录。
5. 端口：ss/netstat 分别解析、端口数值排序、可见页自动刷新/时间/超时与错误、端口关联进程。
6. 监控：隐藏暂停、显示恢复且不重复采集，网卡与挂载点选择，切换目标重置基准，接口枚举/读取错误有明确降级。

独立模块由技能允许的内部代理分别负责编辑器、端口、终端跟踪；主代理负责传输/文件/会话集成与监控，避免共享写入。各模块先增加行为测试，不并行运行共享 Maven 构建。集成后验证真实隔离 SSH/SFTP、排序/选择/取消/冲突/路径边界及断开清理，进行全量 Maven、深浅主题/150% 组件检查、最终 JAR 预览。

真实 Debian/OpenSSH、弱网、多 GB 和人工原生桌面证据单独说明，不以测试 fixture 代替。凭据库、跳板机、SOCKS5 和安装包属于列表后的长期方向，本轮范围为明确编号的六项。

实施完成，具体用法、边界和验证记录见 [六项功能实施说明](six-features-implementation-2026-10-17.md)。
