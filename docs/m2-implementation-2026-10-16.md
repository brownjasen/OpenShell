# 第二批实施与验证记录

日期：2026-10-16

## 状态与范围

本批完成 M2 中的工作区保存、命令辅助输入、主机分组及紧凑布局优化。自动目录跟随、远程路径补全和真实桌面交互验收仍待后续，不代表整条路线完成。

修改范围为 OpenShell 源码、测试与文档。实施前副本位于工作区 `.work2/openshell-m2-baseline-20261016/`，包含第一批源码和旧 JAR。工作区不是 Git 仓库，没有提交、推送或发布；没有读取用户实际保存的连接配置，也没有连接用户服务器。

## 本批行为

| 领域 | 实现与使用方式 |
| --- | --- |
| 工作区 | 保存窗口位置/尺寸/最大化、深浅主题、主机侧栏开关与宽度、终端字号。侧栏快捷键 Ctrl+Shift+B。 |
| 会话视图 | 按已保存主机的 ID 保存分屏比例、专注终端/专注文件模式和监控可见性。小窗口临时为文件区留出空间，放大后继续使用原比例。 |
| 文件视图 | 保存目录树宽度、文件表列宽和隐藏文件选项；文件大小按数字排序。路径与操作分两条紧凑工具栏，低频删除操作移到菜单。 |
| 历史 | 按主机保存本地命令输入框成功写入 SSH 的命令，每台最多 1000 条，相邻重复去重；提供搜索、清空和关闭记录。↑/↓ 查看历史并恢复未发送草稿；Alt+/ 按前缀查找本地历史。 |
| 常用命令 | 新增自定义命令管理，支持名称及多行文本；保存后重启可读。内置和自定义命令都只填入草稿。 |
| 目录操作 | “填入 cd”对当前 SFTP 目录生成经过 Shell 转义的命令；已有单行或多行草稿时拒绝替换，用户确认 Shell 就绪后再发送。压缩/解压命令也先填入草稿。 |
| 主机目录 | `/` 分隔的嵌套分组；新建、重命名/移动、删除空分组；移动主机、主机/分组拖动移动。禁止移入自身子分组和覆盖已有目标分组。取消编辑不会修改原配置。 |
| 最近连接 | 仅在成功连接后更新已保存主机的时间，首页与侧栏显示最近记录；快速连接不会自动变成保存的主机。 |
| 界面 | 首页保留连接入口与最近主机；主机及文件使用矢量图标。窄窗口减少监控卡片，修复 150% 缩放下主机栏标题挤压按钮的问题；提供“到底部”入口。 |

文件区快捷键为 F5 刷新、Alt+Left/Right 路径历史、F2 重命名、Ctrl+L 编辑路径；限定在文件区内生效。主窗口实际绑定 Ctrl+N 新建、Ctrl+Shift+N 快速连接、Ctrl+Shift+W 关闭当前会话/编辑标签。

## 设置与数据

- 新文件 `%USERPROFILE%/.openshell/workspace.json` 保存工作区、分组元数据、输入历史和自定义命令。可用 `openshell.configDir` 隔离目录。
- 设置读写使用同目录临时文件、同步和替换，损坏的文件不自动覆盖；读写失败有状态或对话框反馈。尺寸、分屏比例、字号与历史数量有边界归一化。
- 同一进程内采用读改写合并，避免会话布局保存覆盖文件视图字段；不声称支持多进程并发写入。
- 主机与分组元数据分别位于 hosts.json 和 workspace.json；不是跨文件事务。主机保存成功但分组元数据失败时会提示，不承诺两者同时提交。
- 历史默认开启且为本机明文；可以从“历史”窗口关闭记录或清空当前主机记录。直接在终端内敲入的内容不会被此输入历史功能采集。自定义命令也以明文保存。
- 收起监控只改变可见性，尚不暂停后台采样。正常关闭会刷新尚未落盘的延迟设置；强制终止时最近 400ms 内的拖动/窗口变更可能尚未保存。

## 验证

最终构建命令（工作区根目录）：

```powershell
./OpenShell/build.ps1 -LocalRepository ../.work2/m2
```

- `clean verify` 成功：27 项测试，失败 0，错误 0，跳过 0。第一批 17 项回归保持通过，本批增加 10 项。
- 新增覆盖设置重读、不同视图字段合并、损坏文件保留、历史隔离/去重/上限/关闭记录、自定义多行命令保存、嵌套分组边界、移动/删除空分组、取消变更隔离、最近连接保存、会话布局恢复及文件树/列宽/隐藏选项恢复。
- 隔离 SSH 服务实际验证：填入草稿不写入 Shell，不覆盖已有草稿；显式发送后服务端收到输入并保存本地历史。SFTP 列表大小排序使用真实文件，避免按格式化字符串排序。
- 会话工作台在 1100×700 和 670×450 的组件区域生成图片；紧凑区域断言至少一行文件可见。组件区域尺寸不等于整个主窗口尺寸。
- 使用 `-Dflatlaf.uiScale=1.5 -Djava.awt.headless=false` 对会话和工作区交互测试做定向复核，5 项通过；检查对应普通/紧凑组件图片。
- 最终 JAR 在仅有打包应用与检查入口的类路径上，普通和 150% FlatLaf 用户缩放均完成终端构造、MainWindow 构造/释放，输出 `PACKAGED_APP_SMOKE_OK`；1366×768 主窗口根面板生成图片。
- 运行环境沿用 Windows 11 / Oracle JDK 21.0.4 / Maven 3.9.12，以 `--release 17` 编译。测试服务器为临时目录、内存密钥及本机回环端口。

证据为自动化协议检查和未显示窗口的组件渲染；没有执行桌面鼠标拖放、模态对话框逐项点击、输入法/剪贴板、真实显示器 DPI 或真实 Linux vim/top/less 验收。没有把 FlatLaf 用户缩放渲染视为 Windows DPI 桌面验收。测试服务不提供 Linux 指标，截图中的监控不可用是预期状态。
