# 六项功能实施与使用说明

本轮按用户授权完成六项。保留原有主题、分屏布局和终端快捷键。没有读取或修改实际保存的连接、没有连接用户服务器；没有提交、推送或部署。

## 入口与行为

| 功能 | 使用方法 | 结果 |
| --- | --- | --- |
| 在线编辑安全保存 | 编辑文件后 Ctrl+S | 读取远端内容摘要作版本检查；冲突时可并排比较、确认重载、另存副本或明确覆盖。先写同目录临时文件再替换，失败保留编辑内容和本地副本。另存路径指向原文件时拒绝。 |
| 批量文件 | Ctrl/Shift 多选，点击下载或按 Delete | 排序、过滤后仍按真实选中项操作。删除确认列出固定绝对路径，逐项报告失败；目录仅在为空时删除。 |
| 文件夹传输 | 上传时选择文件/文件夹，或将本地文件/文件夹拖入文件表；下载可选择远端文件夹 | 后台整理后整批加入队列，保留层级和空目录。同名目录合并，文件冲突仍由用户选择。显示批次总大小与进度，支持取消本批、仅重试失败项。整理阶段可取消，断线立即停止。 |
| 目录衔接 | 文件页“书签”；“操作 → 跟随终端目录 / 启用当前 Bash 会话目录集成”；草稿 Ctrl+Space 或“补全” | 书签与跟随偏好按主机保存。默认不跟随；集成脚本仅填草稿，用户发送后在当前 Bash 会话发出 OSC 7。补全通过独立 SFTP 读取目录，只修改草稿。 |
| 端口管理 | 打开端口页，点击表头排序，选端口后“查看进程” | 分别解析 ss/netstat、IPv4/IPv6、UDP、PID；端口/PID 按数字排序。自动刷新开关、最近更新时间、超时/错误可见；关联 PID 在进程页精确定位。 |
| 资源监控 | 勾选“监控”；资源栏右侧 ⋮ | 隐藏监控或会话时停止远端采集，显示恢复时重新采样；可选网卡和磁盘挂载点，切换后清空旧基准，首次 CPU/速率显示等待值。旧线程不能向新一轮采样写入。 |

## 保留与限制

- Bash 集成不写 `.bashrc` 等启动文件，不自动执行命令；保留已有提示符钩子与退出状态。其他 Shell 可自行发出标准 OSC 7。终端 Tab 仍交给远端；本地历史补全仍用 Alt+/。
- 监控设置当前在本次会话内保留。自动网卡模式合计非回环网卡，网桥/VPN 可能重复统计，可选实际网卡。进程/端口无需自动 sudo；无权限的进程信息显示不可见。
- 递归传输不跟随符号链接或特殊文件；远端祖先也检查。不安全的 Windows 名称、大小写碰撞、路径越界会使整理失败，未完成整理前不提交部分批次。最大 100000 项、128 层；远端整理 60 秒截止，大目录可分批。目录扫描和文件字节传输均可取消。
- 已有目录合并，目录任务不作整体原子回滚；取消后已完成文件和已建目录保留。重试为从头传输，断点续传尚未实现。源/目标目录被外部改动会检查并报错。
- 在线编辑支持 UTF-8 普通文件，最大 20 MiB。覆盖已有远端文件要求服务端支持 POSIX rename；缺少能力时保留原文件并提示另存。SFTP 没有内容比较并替换的原子 CAS，最终校验到 rename 之间仍有很短的外部修改竞争窗口。
- 本地/远端覆盖均沿用临时文件发布；网络在最终 rename 后中断时，结果可能需要用户核对。没有删除原目标后重试 rename 的回退。
