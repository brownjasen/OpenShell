## 实现

- JediTerm 3.76 替换 JTextArea 输出终端。连接适配层保留控制序列，连续解码字符，传递 PTY 尺寸；保留单行/多行编辑、历史和分类常用命令。
- SessionController 以连接代次隔离异步结果，支持连接取消、重连、失败、断开、关闭；会话数量按真实连接状态计算。每次连接固定主机配置快照。
- 首次连接显示算法和 SHA256 指纹；保存至 known_hosts，拒绝已有主机的密钥或算法变化。连接失败回收已建立资源。
- 工作台上方保留终端，下方切换文件/进程/端口/隧道；提供专注终端与专注文件布局。
- SFTP 目录枚举不再 cd；后台文件操作固定绝对路径，目录请求使用序号丢弃旧结果。远端 Shell 文件名采用单引号转义。
- 在线编辑只在加载成功后允许操作，保存使用 UI 文本快照；显示修改标记，关闭时支持保存/放弃/取消，保存失败保留编辑内容。成功保存改用状态提示。
- 关闭主机先处理关联编辑器；关闭其他标签时保留正在使用的编辑器所依赖的连接。
- 配置与导出先序列化，再写同目录临时文件、同步并替换；序列化失败、配置损坏与 JSON null 不再静默覆盖旧数据。
- SOCKS5 的无效创建入口已隐藏，防止把固定转发显示为动态代理。
- 联调中发现监控命令 EOF 后会快速重试，已增加两秒退避；无有效采样显示不可用或等待，不显示伪造的成功状态。
- 增加项目构建脚本、隔离 Maven 设置和官方终端依赖预取工具。所有缓存位于指定工作区目录，不修改系统 Maven 配置。
