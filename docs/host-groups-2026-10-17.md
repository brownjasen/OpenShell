# 连接侧栏与分组调整

- 显示顶层分组的展开箭头，收窄每级缩进，分组使用较小图标和标题字体，主机使用两行信息；右侧显示该分组包含的主机数量，嵌套分组计入后代主机。
- “最近连接”使用时钟图标，默认收起，避免同一主机在侧栏中重复展开。新增可选工作区字段 `recentExpanded` 保存开合选择，旧配置缺省为 false；普通分组继续使用已有的 `collapsedGroups`。
- 保存连接记录、刷新或切换主题时保留选中项，区分普通分组中的主机与最近记录的快捷入口。搜索时不更改原有的分组开合选择。
- 侧栏文字按可用宽度布局，长名称、地址使用省略显示；悬停显示完整连接信息，取消横向滚动条。搜索框提示收为“搜索连接…”，搜索范围保持名称、地址、用户名与分组。
