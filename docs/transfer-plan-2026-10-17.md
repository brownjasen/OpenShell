# 传输队列实施计划

范围：本批完成文件上传/下载队列、独立传输通道、进度/速度/取消/从头重试和同名处理。保持现有工作台布局，在文件工具栏增加传输入口，下方增加传输标签。文件夹递归、拖入上传、断点续传和在线编辑冲突检测另批处理。

1. 建立每个会话独立的串行传输队列，提交时固定本地与远端绝对路径；状态包括等待、传输、等待冲突选择、完成、跳过、取消、失败。按序执行，关闭后拒绝新提交并隔离旧视图回调。
2. 每项任务使用新的 SFTP 通道，与浏览/编辑通道分离。同名提供覆盖、保留两者、跳过。写入同目录临时文件，完成后检查来源与目标变化再替换；不以先删除目标来兼容不支持替换的服务端。
3. 传输页显示方向、文件/目标、大小、进度、速度、状态及失败原因；可取消、重试失败/取消项、清理结束项。显示正在完成阶段，防止把已经发布的结果误报为取消。
4. 上传成功后按固定路径刷新当前目录；断线停止队列并显示结果，重连创建新队列。关闭有未完成任务的会话时明确提示取消后果。
5. 行为测试先覆盖队列串行、独立通道浏览、取消后旧文件保留、重试、同名处理与路径固定；本机隔离 MINA SSH/SFTP 服务验证真实协议与文件内容。测试不连接已保存主机、不读取用户凭据。
6. 全量 Maven 验证、100%/150% 深浅主题组件预览和打包。记录尚未通过真实 Linux、网络异常或服务器能力验证的边界。

注意：SFTP 属性校验不能提供跨客户端的原子比较并替换锁；不支持安全替换时保留原目标并报告失败。远端连接在清理前中断时，临时文件可能保留，错误信息应包含其路径。
